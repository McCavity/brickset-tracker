# SOP-007 — Internationalisation (i18n)

**Layer:** Tool (execution)
**Goal:** Provide bilingual (German / English) UI strings loaded at startup from JSON locale files. Zero external dependencies. Language switchable at runtime via UI toggle.

---

## Locale Files

```
locales/
  de.json   ← German (default)
  en.json   ← English
```

Both files share identical key structure. Missing keys in `en.json` fall back to `de.json`. Missing keys in `de.json` return the raw key string (so broken translations are visible immediately).

## Server-Side Helper

```python
# execution/i18n.py

import json
from pathlib import Path

_locales: dict = {}

def load_locales():
    for lang in ("de", "en"):
        path = Path(f"locales/{lang}.json")
        _locales[lang] = json.loads(path.read_text(encoding="utf-8"))

def t(key: str, lang: str = "de", **kwargs) -> str:
    """Resolve a dot-separated key, e.g. t('errors.not_found', lang='en')"""
    parts = key.split(".")
    # Try requested language first, fall back to German, then raw key
    for locale in (lang, "de"):
        node = _locales.get(locale, {})
        for part in parts:
            node = node.get(part) if isinstance(node, dict) else None
            if node is None:
                break
        if isinstance(node, str):
            return node.format(**kwargs) if kwargs else node
    return key  # last resort: return the key itself
```

## Language Detection & Switching

1. Client stores chosen language in `localStorage` key `"lang"` (default: `"de"`).
2. Every API request that needs a translated string sends `Accept-Language: de` or `Accept-Language: en` header.
3. FastAPI reads the header and passes `lang` to `t()`.
4. The UI language toggle sets `localStorage["lang"]` and reloads the page.

## Condition Enum i18n

The condition values (emoji + text) are stored in the DB as the **German string** always (canonical form). The `condition` key in locale files maps an internal key to the display string. The UI displays the locale-appropriate label; the DB always stores the German canonical value.

```
DB value:               "📦 OVP — gekauft, ungeöffnet"
de display (same):      "📦 OVP — gekauft, ungeöffnet"
en display (translated): "📦 Sealed — bought, unopened"
```
